# CLEANDEX

Pokédex mobile feita em React Native + Expo que consome a [PokeAPI](https://pokeapi.co).

## Requisitos

- [Node.js](https://nodejs.org) (versão LTS) e npm
- App [Expo Go](https://expo.dev/go) no celular, ou um emulador Android/iOS

## Quick start

```bash
git clone <https://github.com/LucasGSanches/cleandex.git>
cd cleandex
npm ci
npx expo start
```

Escaneie o QR code com o Expo Go (o celular precisa estar na mesma rede Wi-Fi do computador), ou aperte `a` para abrir no emulador Android ou `w` para abrir no navegador.
